# Vaishnavi Balasubramaniyan Portfolio

Static portfolio website prepared for GitHub Pages.

## Recommended GitHub Pages URL for the connected account

Authenticated GitHub username detected: `vaishnavi-balasubramaniyan`

Use this repository name:

```text
vaishnavi-balasubramaniyan.github.io
```

After publishing, the site URL will be:

```text
https://vaishnavi-balasubramaniyan.github.io/
```

## Files

- `index.html` - portfolio homepage
- `Vaishnavi_Balasubramaniyan_Resume.pdf` - downloadable resume linked from the homepage
- `.nojekyll` - tells GitHub Pages to serve the static files directly

## Browser upload steps

1. Create a new public GitHub repository named `pravinkumarvr.github.io`.
2. Upload `index.html`, `Vaishnavi_Balasubramaniyan_Resume.pdf`, and `.nojekyll` to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Open `https://pravinkumarvr.github.io/` after GitHub Pages finishes deployment.

## Terminal publish option

Install and authenticate GitHub CLI, then run:

```bash
cd vaishnavi_github_pages_publish_package
bash publish_with_github_cli.sh
```
